# Netum.Truugo.ValidatorListProfiles

Task for calling Truugo Validator List Profiles endpoint. You can refer to Truugo API Swagger here: https://api.truugo.com/reference/. Please note that in order to use this task, you need Truugo API Credentials.

## Installing

You can install the Task via Frends UI Task View.

## Building

### Clone a copy of the repository

`git clone https://github.com/FrendsPlatform/Netum.Truugo.git`

### Build the project

`dotnet build`

### Run tests

Run the tests

`dotnet test`

Get unit test coverage

`dotnet test --collect:"XPlat Code Coverage"`

### Create a NuGet package

`dotnet pack --configuration Release`
